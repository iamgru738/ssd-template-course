# AGENTS.md

## Бізнес

Навчальна копія сайту Фундації Лятошинського для курсу spec-driven-ba-workshop. Сайт показує спадщину Бориса Лятошинського: життєпис, творчість, дослідження, архів, новини, співпрацю та підтримку фундації. Для відвідувача це демонстраційні матеріали: між сесіями зміни не зберігаються, після нового запуску знову видно початковий набір.

### Сторінки

| Сторінка | Адреса на сайті | Бізнес-призначення |
| --- | --- | --- |
| Головна | `/[lang]` | Вхід на сайт: спадщина композитора, події, новини, співпраця та перехід до архіву |
| Життєпис | `/[lang]/biography` | Біографія Бориса Лятошинського |
| Творчість | `/[lang]/artistry` | Каталог творів і матеріалів про музичну спадщину |
| Дослідження | `/[lang]/research` | Наукові роботи та дослідження |
| Архів | `/[lang]/archive` | Перелік фондів архіву композитора |
| Архівна справа | `/[lang]/archive/[fund]/[case]` | Перегляд конкретної справи: документи, листи, рукописи та інші джерела |
| Про фундацію | `/[lang]/about-us` | Місія, назва та цілі організації |
| Новини | `/[lang]/news` | Новини, події та згадки в медіа |
| Співпраця | `/[lang]/cooperation` | Умови партнерства для партнерів, благодійників і меценатів |
| Підтримати | `/[lang]/support-us` | Разовий внесок або підписка на рахунок фундації |
| Контакти | `/[lang]/contacts` | Форма запиту; відповідь протягом кількох робочих днів |
| Війна в Україні | `/[lang]/war-in-ukraine` | Робота фундації та ініціативи під час війни |
| Політика конфіденційності | `/[lang]/privacy-policy` | Збір, використання і захист персональних даних |
| Умови користування | `/[lang]/terms` | Правила доступу до матеріалів і обов’язки користувача |

`[lang]` в адресі — мова сторінки для відвідувача. Українська є основною мовою сайту, англійська — другою.

## Технічні вимоги

- Код пишеться на TypeScript.
- Експортуйте іменовані функції та компоненти. Default export не використовуйте.
- Основна локаль — `uk`. Друга локаль — `en`. `defaultLocale` у `i18n/routing.ts` — `uk`.
- Це навчальний репозиторій. База даних скидається при кожному запуску: in-memory MongoDB створюється заново під час `npm run dev`, наповнюється демо-даними і зникає, коли застосунок зупиняється.
